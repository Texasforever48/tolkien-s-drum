# Tolkien 的鼓

一个轻量的架子鼓练习计时器。

[打开网站](https://texasforever48.github.io/tolkien-s-drum/)

## 练习

- 单击练习：5 分钟
- 基本摇滚节奏：10 分钟
- 跟歌练习：10 分钟

每项独立计时，支持开始、暂停、继续和重置。完成后可重新开始；刷新页面会重置计时。

## 本地使用

将 `index.html` 和 `background.css` 放在同一目录，用浏览器打开 `index.html`。无需安装依赖或运行构建命令。

## 代码

- `index.html`：页面结构、基础样式和计时逻辑。
- `background.css`：纯 CSS 动态背景；系统开启“减少动态效果”时停止动画。

使用原生 HTML、CSS 和 JavaScript，通过 GitHub Pages 发布。
